# HomeBrew常用指令

1. 核心安装指令
    
    `brew install <formula>`  ：安装软件包(如 `nano` ,`bat` ,`fzf` )
    
    `brew install --cask <app>` ：安装带界面的macOS应用(如 `ghostty` ,`visualstudio-code` , `rstudio` )
    
    `brew uninstall <name>` ：卸载软件包
    
    `brew list`  ：列出你所有通过Homebrew安装的东西
    
2. 日常维护
    
    `brew update` ：获取最新清单。不会更新软件，只是下载最新软件的目录，告诉哪些东西有新版本了
    
    `brew upgrade` ：正是更新软件。将电脑里所有旧版本的软件包升级到最新版
    
    `brew outdated` ：查看哪些软件已经过时了，但还没升级
    
3. 清理与空间回收
    
    由于Homebrew在更新时会保留旧版本的安装包，久而久之会占用很多空间
    
    `brew cleanup` ：删除旧版本。它会清理掉已经没用的旧版文件，释放硬盘空间
    
    `brew cleanup -n` ：先查看能清理多少空间，但不实际动手
    
4. 搜索与查询
    
    `brew search <name>` ：模糊搜索。如果不确定R语言的软件包叫什么，输入 `brew search r`
    
    `brew info <name>` ：查看软件详情。它会告诉你这个软件安装在哪儿，大小，以来，以及有哪些特殊配置
    
    `brew home <name>` ：直接在浏览器里打开该软件的官网
    
5. 排难解惑(没反应或报错)
    
    `brew doctor` ：体检指令。会扫描系统的环境配置，告诉哪里设置错了(比如路径不对，权限问题等)，并给出修复建议
    

# Ghostty 常用指令

1. 窗口与分屏
    
    `CMD + D` : 垂直分屏
    
    `CMD + Shift + D` : 水平分屏
    
    `CMD + [` or `CMD + ]`  : 分屏之间切换光标
    
    `CMD + Shift + Enter` ：最大化当前分屏
    

# Nano常用指令

**`^ 代表 Control 键`**

1. 保存与退出
    
    `Ctrl + O (Write Out)`: 保存。按下后会问文件名，直接 `Enter`  确认
    
    `Ctrl + X (Exit)`: 退出。如果修改了没保存，他会问你 `Save modified buffer?`  ，按 `Y` 是保存并退，按 `N` 是不保存强退
    
2. 导航与搜索(快速定位)
    
    `Ctrl + W (Where is)` ：搜索关键词。在配置文件中找东西
    
    `Ctrl + _ (后接行号)` ：跳转到指定行。比如运行代码提示“第82行有错”，`Ctrl_82` 跳转到指定行
    
3. 编辑操作
    
    `Ctrl + K (Cut)` : 剪切/删除整行
    
    `Ctrl + U (Uncut)` : 粘贴刚才剪切的行(相当于简单版的剪切板)
